# nirius 功能

## 查找与切换

- **窗口筛选**：按应用、标题、进程、工作区或窗口状态组合筛选，支持正则匹配。

- **快速聚焦**：切换到匹配窗口，或在多个匹配窗口间循环。

- **聚焦或启动**：有匹配窗口就切换，没有就启动应用。

## 窗口召回

- **召回到当前工作区**：将匹配窗口移到当前工作区，可同时聚焦。

- **召回或启动**：有可召回窗口就移过来，没有就启动应用。

## 窗口标记

- **标记管理**：为窗口添加或移除标记，支持多个自定义标记。

- **按标记切换**：在同一标记下的窗口间循环切换。

- **标记列表**：查看指定标记或全部标记下的窗口。

## 窗口跟随

- **始终跟随**：切换工作区或显示器时，窗口跟随到当前工作区。

- **按需跟随**：窗口仍可见时留在原处，不再可见时才跟随。

## 窗口暂存（Scratchpad）

- **加入与移出**：切换窗口的暂存状态，也可保持窗口原位。

- **单个呼出**：按条件或窗口标识呼出暂存窗口，支持循环呼出与收起。

- **批量呼出**：一次呼出或收起全部暂存窗口。

- **自动避让**：进入仅含暂存窗口的底部工作区时，将它们移到下方。

- **自动解除**：窗口改为平铺时，自动退出暂存区。

- **暂存列表**：查看全部暂存窗口。
