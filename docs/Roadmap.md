# Roadmap

## 已完成

- [x] **修饰键独按**：Super／Hyper 等支持短按、长按独立绑定，同时保留组合键使用。
- [x] **[窗口查询与聚焦](feat/window-selection.md)**：通过 CLI／IPC 列出、筛选窗口，通过 CLI／KDL／IPC 按条件聚焦；文本列表支持按工作区分组。

## Niri 原生

- [ ] **特定窗口唤来／唤去**：快速把需要的窗口叫到面前，用完后唤去，再次调用能找到目标窗口。
- [ ] **Agent 指定窗口截图**：让 agent 方便地找到目标窗口并获取截图。
- [ ] **应用快捷直达**：已有按条件聚焦，待补无匹配窗口时启动应用。
- [ ] **窗口标记与召回**：给具体窗口命名或分组，通过标记快速找到它。
- [ ] **窗口暂存**：把暂时不用的窗口收起，需要时恢复。
- [ ] **窗口跟随**：让视频、音乐等窗口在切换工作区时保持可用。
- [ ] **工作区列宽统一切换**：一次调整当前工作区内各列的宽度。
- [ ] **窗口透明度调节**：方便地调整窗口透明度。

## Niri Tools

- [ ] 应用启动器
- [ ] 高性能壁纸守护进程（支持动态壁纸）
- [ ] 图形化的配置 UI

## Shell 集成/插件

- [ ] **网格应用启动器**：通过 Super+Space 打开，以图标网格浏览、搜索和启动应用。
- [ ] **蓝牙设备管理**：方便地发现、配对、连接和断开设备，清楚展示连接状态与失败原因。
- [ ] **新机器环境复现**：在新机器上恢复这套桌面功能和个人使用习惯。
- [ ] **快捷键面板**：随时查看可用快捷键及其作用。
- [ ] **录屏**：方便地开始、停止录制并找到录制结果。
- [ ] **窗口信息查看与复制**：快速获取窗口的应用标识、标题等信息。
