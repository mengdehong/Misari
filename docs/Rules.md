# 命名与版本规则

misari 是个人维护的基于 niri 开发的桌面项目。

## 命名与安装

- 项目与安装包名使用 `misari`，安装路径、命令、配置路径、IPC 与桌面环境标识均保留为 `niri`。
- 安装包提供 `niri`，与官方 `niri` 包冲突。

## 版本

misari 版本采用 `上游版本.vX.Y`，例如 `26.4.0.v1.0`。`X` 为个人功能发布号，`Y` 为修复号。

| 变化 | 版本示例 |
| --- | --- |
| 基于该上游版本首次发布 | `26.4.0.v1.0` |
| 新增或调整功能 | `26.4.0.v2.0` |
| 修复该版本的问题 | `26.4.0.v2.1` |
